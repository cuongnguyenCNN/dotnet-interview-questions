# .NET Interview Questions

A practical collection of .NET interview questions for developers preparing for Mid-Level and Senior .NET interviews.

The goal isn't to memorize answers.

The goal is to understand **how Senior engineers think about problems.**

## Topics

### 01. C#

Core C# concepts, async programming, LINQ, memory management, and language features.

### 02. ASP.NET Core

Dependency Injection, middleware, APIs, authentication, authorization, configuration, and application architecture.

### 03. EF Core

LINQ, query execution, tracking, transactions, concurrency, migrations, and database performance.

### 04. Architecture

Clean Architecture, Modular Monoliths, Microservices, CQRS, Event-Driven Architecture, and distributed systems.

### 05. System Design

Scalability, caching, messaging, databases, load balancing, rate limiting, and distributed systems.

### 06. Performance

.NET performance, database optimization, caching, async programming, memory, profiling, and production troubleshooting.

## How to Use This Repository

Don't just read the answers.

For every question, try to answer it yourself first.

Then compare your answer with the Senior-Level Thinking section.

A strong interview answer should explain:

1. What it is
2. Why it matters
3. When to use it
4. What can go wrong
5. The trade-offs
